## Mini guide pour installer et utliser obsidian depuis le repo github.

#### 1. Installation d'obsidian sur ubuntu:
Commande d'installation:
- sudo snap install obsidian --classic

tuto bonus : 
pour pouvoir dessiner des schemas installer le plugin excalidraw:
Settings -> Community plugins -> Browse -> chercher Excalidraw -> Install -> enable

### 2. Lancement d'obsidian
Après l'installation complète lancer obsidian, quand tu arrive sur la page d'acceuil.
Clique sur "open folder as vault" et parcour ton pc jusqu'a arriver au dossier du repo.
tu peux maintenant modifier et ajouter des fichier de documentation !
